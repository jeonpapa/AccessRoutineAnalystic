# PR-NEW-001 — 경평소위 직전 통과 → 다음 약평위 상정 패턴

## 정의

심평원의 경제성평가소위원회(경평소위, Pharmaco-Economic Evaluation Sub-Committee)는 약평위 본 회의 전 단계의 경제성평가를 수행한다. 경평소위에서 약물의 경제성평가가 통과되면 가장 가까운 다음 약평위 안건으로 상정되는 패턴.

본 룰은 **본 시스템이 사전 신호 source로 경평소위 통과 보도를 추적하면 약평위 안건 후보 예측 정확도(recall)가 향상**될 가능성을 시사한다.

## 발견 case (FN으로부터 학습)

### 2026-06-04 6차 약평위 — FN
- **빌로이주** (한국아스텔라스, CLDN18.2+ 위암 1차)
- **5/22 경평소위 통과** → 6/4 약평위 상정 → 무조건 통과
- 약 13일 lag — 매체 사전 보도 있었으나(메디칼옵저버 등) 본 시스템 v8 D-2 예측에 누락

## 검증 이력

### 2026-07-02 7차 약평위 — 신호 미추적 (시스템 미적용)

7차 약평위 D-2 예측에서 경평소위 신호를 추적하지 않아 아래 5건 FN:
- 엑스코프리 (세노바메이트, 뇌전증)
- 넴루비오 (네몰리주맙, 아토피)
- 스프라바토 (에스케타민, 치료저항성 우울증)
- 팁소보 (이보시데닙, 담관암)
- 옥스루모 (루마시란, 원발성 고옥살산뇨증)

→ **본 룰 적용 시 TP 가능성 있었으나 실제 추적 부재로 검증 불가**. CANDIDATE TP count +0 (추적 미시행).

**결론**: CANDIDATE 검증을 위해서는 실제 경평소위 신호 탐색 루틴 구축이 선행 필요.

## CANDIDATE 검증 시나리오

- **다음 차수(8/6 8차)에서 경평소위 통과 약물이 안건되어 통과** → TP +1
- **연속 2회TP** → ACTIVE 승격 (weight 0.65 → 0.70)
- **FP 누적** → 폐기
